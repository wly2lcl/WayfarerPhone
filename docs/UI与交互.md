# UI 与交互设计

> 版本：v0.3（单机离线）
> 最后更新：2026-10-27
> 上游：[产品方案](./产品方案.md) ｜ 配套：[M0 内容包](./M0内容包-修真.md)

阅读体验是这个品类的第一印象。界面要往后退，文字要往前站。

---

## 1. 设计原则

1. **沉浸优先**：游玩页 80% 的屏幕留给正文，控件能折叠就折叠。
2. **温暖纸质**：暖白纸面、墨色文字、朱红点缀，不做深色科技风。
3. **克制动效**：只保留流式打字与必要的淡入，不加粒子、发光、3D 翻转。
4. **状态可见但安静**：数值用细线和小字，不抢正文的注意力。
5. **一次只让玩家做一个决定**：选项不做并列选项卡堆叠，按推荐顺序纵向排列。

## 4. 游玩页布局

```
┌──────────────────────────────────────┐
│ 第三章 · 药庐的雨          [助手] [⋯] │  顶部 44–56
├──────────────────────────────────────┤
│                                      │
│   你把手缩进袖子里。风从山门那边过来，  │  正文区
│   带着一股铁锈味。                     │  可滚动、流式追加
│                                      │  左右留白 24
│   守门的弟子看了你一眼，又低下头去。    │  行高 1.9
│                                      │
│                                      │
├──────────────────────────────────────┤
│ 气血 ▓▓▓▓▓░░░ 62   寿元 118/120  ▾  │  状态条 36（可折叠）
├──────────────────────────────────────┤
│ ○ 拦住守夜人，问他昨夜去了哪           │  选项区
│ ○ 什么也不问，先回药庐                 │  每项 52，纵向排列
│ ○ 去三合堂打听消息                     │
├──────────────────────────────────────┤
│ 你还想做什么？                  [发送] │  自由输入 48
└──────────────────────────────────────┘
```

### 状态条规则

- 默认只显示 气血 与 寿元，其余收起；点击展开 6 项全量
- 关系以 NPC 名字 + 一个词呈现（「苏晚 · 亲近」），不显示数字
- 数值变化时用 300ms 的一次性高亮，不做持续脉冲
- 面板数据**只来自 `state_patch`**，不解析正文

### 选项区规则

- 3–4 项，纵向，每项左侧一个风险圆点（低/中/高，用中性灰阶而非红绿）
- 条件不足的选项不隐藏，改为「？」并置灰，点击给出角色视角的理由
- 选中后整块淡出 150ms，正文随即开始

### 自由输入规则

- 常驻底部，占位文案随场景变化（「你还想做什么？」「说点什么」）
- 发送后输入框锁定，直到本回合结束
- 若被判定为「越权」，不做系统提示，直接进入叙事

### 离线与模型状态

- 生成正文需要网络；阅读已落库的回合不需要网络。
- 未配置 Key：正文照常可读，选项区替换为一张「先配置模型」卡片，输入框置灰；卡片跳设置页。
- 请求失败：顶部出现 28 高的细条「网络中断，已保留本回合已生成的内容」，右侧「重试」；正文不清空、不重复追加。
- Key 无效或余额不足：细条显示供应商错误码与一句建议，提供「去设置」。
- 模型流中断且有部分正文：部分正文入库并标记「未完成」，重试只续写缺失部分。
- 顶部不常驻网络图标；只在失败时出现细条，恢复后 2 秒自动收起。

## 5. 关键交互时序

模型调用由 App 直接发往用户配置的端点（三种协议之一），渲染仍走 App 内事件流，模型 HTTP 流只负责产出增量文本。

| 时刻 | 行为 |
| --- | --- |
| 玩家选择 | 选项淡出 → 输入锁定 → 回合进入进程内串行队列 |
| 收到 `turn_start` | App 内事件：顶部切换为「正在发生」，正文区准备追加 |
| `narration_delta` | 模型 HTTP 流增量逐字追加；用户上滑则停止自动跟随，出现「回到最新」 |
| `narration_end` | 停顿 200ms，选项区淡入 |
| `state_patch` | 状态条更新并高亮变化项；正文与状态在同一本地事务落库 |
| `turn_end` | 自动滚动到底，恢复输入 |
| 网络失败 | 顶部细条 + 「重试」，保留已生成正文 |
| 重复提交 | 状态机在 `submitting` 期间忽略新提交，队列只接受一次，不产生第二个请求 |
| 应用被系统杀死 | 重启回到最后一个已落库回合，未落库的流式文本丢弃 |

### 章节转场

只在 `beat: 'chapter_end'` 时做一次纸页翻动效果（400ms），并插入一页分隔：卷名、时间、一句卷记。不做每次回合的转场动画。

## 6. 视觉语言

| 角色 | 值 |
| --- | --- |
| 纸面底色 | `#F6F1E7` |
| 卡片面 | `#FBF7EE` |
| 主墨色 | `#2A2622` |
| 次墨色 | `#6B635A` |
| 分隔线 | `#DED5C4` |
| 朱红点缀 | `#A63D2F` |

- 正文：思源宋体 17sp，行高 1.9，段间距 16
- 标题：霞鹜文楷 20sp，仅用于卷名与章节
- 数字：Inter，等宽
- 圆角 12；不用阴影，用细线与留白分层
- 不使用渐变、发光、玻璃拟态

### 夜读模式

暖黑底 `#16130F`，文字 `#E8E0D2`，朱红降饱和为 `#C4573F`。**不用纯黑**，避免长时间阅读疲劳。

## 7. 适配

- 手机：单栏，正文宽度不超过 42 个汉字
- 折叠屏展开 / 大屏手机横屏：双栏，左正文右状态与助手，正文仍保持单行 42 字
- 横屏：允许，但正文宽度上限不变，两侧留白增加
- iPad / Mac：可以安装运行，但首发不做专项适配与验收；布局按响应式自然伸缩，不承诺双栏阅读体验

## 8. 边界态

| 状态 | 表现 |
| --- | --- |
| 首次进入 | 进引导：填模型 Key 或「暂不配置」，再选世界 |
| 未配置模型 | 只读浏览：可读序章与已有正文，选项与输入置灰，顶部卡片「配置模型后可继续」 |
| 无网络 | 可读已落库回合；推进时提示「模型需要网络」，输入内容保留 |
| 模型超时 | 「这一段没写完，再来一次」+ 重试，已生成正文保留 |
| Key 无效 / 余额不足 | 展示供应商错误码与建议，直达设置页 |
| 本地用量偏高 | 用量统计页提示估算费用，不拦截当前回合 |
| 内容拦截 | 「这段内容无法生成」，提供换个方式继续 |
| 重复点击发送 | 状态机拦截，不产生第二次请求 |
| 导入校验失败 | 列出字段级原因，选择返回或删除，不入库半成品 |
| 本地存储不足 | 提示清理旧人生档案或世界包，并引导导出备份 |
| 卸载 / 换机 | 首次启动提示「存档只在本机，建议定期导出」 |

## 9. Flutter 结构建议

```
lib/
├─ app/            路由、主题、启动、引导闸门
├─ core/
│  ├─ ai/          OpenAI 兼容 HTTP 客户端、流式解析、错误映射
│  ├─ models/      RunState / Choice / StateDelta 等模型
│  ├─ storage/     Drift：世界、局、回合、正文、用量
│  ├─ security/    flutter_secure_storage 读写 Key
│  ├─ world/       .world 打包、校验、导入导出
│  ├─ queue/       进程内串行回合队列
│  └─ ui/          纸面组件、按钮、分隔线
├─ features/
│  ├─ onboarding/
│  ├─ shelf/
│  ├─ world_detail/
│  ├─ identity/
│  ├─ play/        PlayPage、PlayController
│  ├─ companion/
│  ├─ archive/
│  ├─ library/     我的世界库
│  ├─ settings/    模型与 Key
│  └─ usage/
└─ main.dart
```

状态机（PlayController）：`idle → streaming → awaitingChoice → submitting → idle`，错误进入 `error`，可从 `error` 重试回到上一态；未配置 Key 进入 `blocked`，配置后回到 `idle`。

依赖建议：`flutter_riverpod`、`dio`、`drift`、`go_router`、`freezed`、`flutter_secure_storage`、`file_picker`、`share_plus`、`path_provider`。

## 11. M1–M3 页面

M0 只做引导 → 书架 → 游玩这条主线。以下页面不属于 M0，但入口位置与关键状态先定下来，避免后续返工。契约分别见[世界创造与导入](./世界创造与导入.md)与[世界分享](./世界分享与UGC.md)。

| 页面 | 阶段 | 关键内容 | 关键状态 / 动作 |
| --- | --- | --- | --- |
| 世界工坊 WorldStudio | M1 | 我的本地草稿列表，按状态分组 | 新建、继续创作、删除草稿 |
| 创作对话 CreateChat | M1 | 与 AI 的访谈式对话 + 右侧实时世界卡 | 回答、跳过、`「可以了」` 生成本地草稿 |
| 草稿编辑器 DraftEditor | M1 | 世界卡分区编辑、校验问题列表 | 逐项修复、试玩、导出 `.world` |
| 导入向导 ImportWizard | M2 | 选文件 → 合成档位（快速/标准/忠实，默认标准）→ 解析进度 → 实体审阅 → 试玩 | 断点续跑、取消、重试、失败后换档重新生成 |
| 试玩 TrialPlay | M1 | 与游玩页相同，顶栏标注「试玩」 | 退出试玩、回编辑器 |
| 我的世界库 WorldLibrary | M2 | 本地世界列表、来源、版本、许可证、AI 标识 | 导入、导出、删除、复制为新草稿 |
| 世界库管理 ManagePage | M3 | 世界列表（名称/占用空间，可按名称或空间排序）+ 导入原文缓存统计 | 导入 `.world`、进入世界详情 |
| 世界详情管理菜单 | M3 | 顶栏菜单：导出分享 / 重命名 / 删除（仅 `exportable=1` 的世界显示「导出分享」） | 删除有存档时二次确认并说明影响 |
| 我的局 · 存档包 | M3 | 局卡片操作：导出（仅非试玩且世界 `exportable=1`）/ 继续 / 档案；顶栏导入 `.run` | 导入成功提示 runId 冲突改后缀 |
| 人生档案 · 人生卡片 | M3 | 「导出人生卡片」按钮 | 纯文本经系统分享面板发出，带 AI 生成角标 |
| 用量统计 UsageStats | M2 | 回合数、token 估算、费用估算 | 按世界/时间查看、重置 |

交互约束：

1. **创作对话不是聊天框产品**。AI 每轮只问一个问题，右侧世界卡实时补全字段；字段齐了才亮「可以了」。玩家说「随便你」时，AI 生成并明确标注哪些是它替玩家定的。
2. **导入必须显示进度与阶段名**（解析 / 抽取 / 合并 /（忠实档）提炼全书脉络 / 待审阅），在本地 Isolate 执行，允许中途离开回来续跑；不允许出现无反馈的长时间等待。
3. **草稿编辑器区分可改与不可改**：AI 生成的结构字段可改，校验失败项必须改，已导出的版本字段只读。
4. **不可导出的世界连入口都不可见**：builtin / 小说导入来源（`exportable=0`）的世界详情菜单只有重命名与删除，没有「导出分享」；我的局列表中此类世界的局不显示「导出」按钮（`RunHead.exportable`）。许可证在冻结时选定并随包携带，AI 生成标识固定写入 manifest（导出者不可关闭），导出时不重复弹窗
5. **人生档案的「分享」是只读人生卡片**（世界名 + 结局 + 历时回合数 + 关键选择 top3），纯文本经系统分享面板发出，带「AI 生成」角标，不含世界包，与 `.world` 是两条链路。

## 12. 世界包导入与导出（M3 实现口径）

- **格式**：`.world` 为 zip（store 模式）容器，内含 `manifest.json`（版本、校验和、许可证、来源、AI 标识、署名）+ `bible.json` + `identities.json` + `seeds.json` + `NOTICE.txt` + `checksum`；不含封面与导入原文（字段定义见[世界分享与UGC](./世界分享与UGC.md) §3）。
- **导出**：世界详情 → 菜单 →「导出分享」→ 本地打包（瞬时完成，无进度 UI）→ `files/exports/` → 系统分享面板；不发起任何上传。`exportable=0` 的世界不显示入口。
- **导入**：世界库管理页 →「导入 .world 世界包」→ 系统文件选择器（`.world` 扩展名过滤）→ 校验 → 写入本地库 → snackbar 报结果。全程离线。
- **校验**：20 MB 上限、zip 结构、`formatVersion` 兼容、必填字段、AI 标识、checksum；失败 snackbar 给出具体原因（错误码 + 消息），不入库。
- **冲突**：同名同版本自动跳过；同版本不同内容默认跳过；更高版本追加；更低版本另存为新世界；标题同名追加「（导入 N）」。不在导入时打断用户做选择。
- **存档包**：我的局 → 局卡片「导出」生成 `.run`；「我的局」顶栏导入图标选 `.run`，成功 snackbar 提示 runId 冲突改后缀，导入局可继续游玩到原进度。
- **展示**：世界详情固定展示来源（内置 / 共创 / 导入 / 分享）、版本号与「AI 生成」标识。
- **流通边界**：无社区、无公开列表、无上传；世界只在用户之间通过文件传递。

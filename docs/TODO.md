## 0. 使用规则

1. **一次只推进一个里程碑**。M0 未通过判定，不开 M1。
2. **一条任务只对应一个可验证产物**。写不出验收的任务，说明还没想清楚，先拆。
3. **顺序不可乱的地方已标「依赖」**，跳过依赖的返工成本由跳过者承担。
4. 完成 M0 后先跑[数据与验证指标](./数据与验证指标.md) §9 的判定，再决定是否进入 M1。
5. 未决事项不改任务状态，统一记在[README 的「尚未决定」](../README.md)。

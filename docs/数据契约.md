## 1. 通用约定

### 1.1 ID 规则

| 前缀 | 用途 | 生成方 | 示例 |
| --- | --- | --- | --- |
| `w_` | 世界 | 内置 / 创建 / 导入 | `w_cangwu` |
| `wv_` | 世界版本 | 冻结 / 导入 | `wv_cangwu_v1` |
| `id_` | 身份 | 内容包 | `id_herb_apprentice` |
| `r_` | 一局 | 开局 | `r_2b9f` |
| `s_` | 快照 | 每回合落库 | `s_r2b9f_0012` |
| `t_` | 伏笔 | 内容包 / 提取 | `t_jade` |
| `npc_` | NPC | 内容包 | `npc_suwan` |
| `seed_` | 事件种子 | 内容包 | `seed_rain_night` |
| `era_` `reg_` `fac_` `place_` | 时代 / 区域 / 势力 / 场所 | 内容包 | `reg_backhill` |
| `c_` | 选项（回合内） | 引擎 | `t18c2` |
| `job_` | 导入任务 | 导入向导 | `job_7a1c` |

规则：

- 全部小写 ASCII，`[a-z0-9_]`，长度 3–40。
- 回合内选项 ID 固定为 `t<turnNo>c<序号>`，同一回合不重复；跨回合可复用序号。
- 快照 ID 固定为 `s_<runId>_<turnNo 四位补零>`，保证可读与可排序。
- 禁止用随机 UUID 直接当业务 ID（可读性差、日志难追）。

### 1.2 时间与数值

| 项 | 约定 |
| --- | --- |
| 落库时间 | Unix 毫秒（UTC），字段名以 `_at` 结尾 |
| 世界内日期 | 字符串 `"<年>-<月>-<日>"`，如 `"317-03-07"`；年可超过 4 位 |
| 世界内日期比较 | 严格按字符串的「年-月-日」数值比较，必须严格递增 |
| 时长 | 回合内推进用 `advanceTimeDays: double`，最小 0.5 天 |
| 数值 | 统一用 `int`，除 `advanceTimeDays`、`completeness`、`progress`、`score` 外不用小数 |
| 百分比 | 0–100 的 `int`，不用 0–1 |

### 1.3 规范化 JSON（仅用于 checksum）

世界包校验和必须可复现，规则固定：

1. 对象键按 Unicode 码点升序排列
2. 无多余空白（`jsonEncode` 默认紧凑输出）
3. 数组保持原顺序
4. 数字不写 `.0`，布尔用小写
5. UTF-8 编码，不转义中文

```dart
String normalize(Object? v) => jsonEncode(_sortKeys(v));

checksum = sha256(
  normalize(bible) + '\n' + normalize(identities) + '\n' + normalize(seeds)
);
```

### 1.4 必填与默认值

- 标 `?` 的字段可缺省；缺省时由引擎补默认值，**不写入 null**。
- 数组缺省为 `[]`，对象缺省为 `{}`。
- 所有结构带 `schemaVersion`（仅顶层 `RunState` 与世界包 `manifest`）；嵌套结构不重复带版本。

## 2. WorldBible（世界圣经）

```ts
type WorldBible = {
  schemaVersion: 1;
  meta: WorldMeta;
  eras: Era[];              // ≥ 1
  regions: Region[];        // ≥ 3（M0 内容包 6）
  factions: Faction[];      // ≥ 3
  powerSystem: PowerSystem;
  taboos: string[];         // ≥ 3
  npcPool: NpcSeed[];       // ≥ 5（M0 7）
  eventSeeds: EventSeed[];  // ≥ 8（M0 10）
  endgame: EndingRule[];    // ≥ 1（M0 4）
};

type WorldMeta = {
  title: string;                     // ≤ 20 字
  genre: 'xianxia';                  // M0 固定
  tone: string;                      // 3–5 个基调词，顿号分隔
  pov: 'second';                     // 第二人称
  language: 'zh-CN';
  contentRating: 'general' | 'teen' | 'mature';   // M0 仅 general
  summary: string;                   // ≤ 120 字，世界卡片用
  volumeHint: string;                // 第一卷骨架，≤ 200 字，进导演系统段
};

type Era = {
  id: string;
  name: string;                      // 如「灵脉枯竭前夜」
  span: string;                      // 如「近三百年」
  summary: string;                   // ≤ 100 字
  turningPoints: string[];           // 转折事件，1–5 条
};

type Region = {
  id: string;
  name: string;
  terrain: 'mountain' | 'plain' | 'river' | 'desert' | 'forest' | 'coast' | 'underground';
  climate: string;
  summary: string;                   // ≤ 100 字
  danger: 1 | 2 | 3 | 4 | 5;         // 危险度，影响环境修正
  factionIds: string[];              // 控制或盘踞的势力，可空
  places: Place[];                   // ≥ 1
};

type Place = {
  id: string;
  name: string;
  kind: 'city' | 'town' | 'sect' | 'wild' | 'ruin' | 'secret';
  summary: string;                   // ≤ 80 字
  tags: string[];                    // 如 ['药庐','后山','禁地']
};

type Faction = {
  id: string;
  name: string;
  kind: 'sect' | 'clan' | 'court' | 'guild' | 'cult';
  summary: string;                   // ≤ 100 字
  goal: string;                      // 一句话目标
  resources: string[];               // 资源或手段
  stanceTo: { factionId: string; stance: 'ally' | 'neutral' | 'rival' | 'enemy' }[];
};

type PowerSystem = {
  name: string;                      // 如「灵根 / 周天」
  resource: string;                  // 如「灵气」
  tiers: Tier[];                     // 3–9 级，按 stage 升序
  rules: string[];                   // 硬规则，≥ 2
  costs: string[];                   // 使用代价，≥ 1
};

type Tier = {
  name: string;                      // 炼气 / 筑基 / 金丹 …
  stage: number;                     // 1..N，严格递增
  maxLayer: number;                  // 该境界层数上限，如炼气 9 层
  lifespan: number;                  // 该境界寿元上限（年）
  requires: string;                  // 突破前置
  breakthroughRisk: number;          // 0–100，基础失败风险
  attrBonus: number;                 // 每层给属性的加成
};

type NpcSeed = {
  id: string;
  name: string;
  role: string;                      // 身份，如「药庐掌柜」
  factionId?: string;
  regionId?: string;
  tier?: string;                     // 修为档位名，可空
  public: {                          // 公开面：可进叙事
    appearance: string;              // ≤ 60 字
    manner: string;                  // 说话与行事风格
    affiliation: string;
  };
  private: {                         // 私密面：只进导演上下文
    secret: string;                  // 秘密，≤ 120 字
    motive: string;                  // 真实动机
    fear: string;
    leverage: string[];              // 把柄或弱点
  };
};

type EventSeed = {
  id: string;
  title: string;
  kind: 'encounter' | 'disaster' | 'opportunity' | 'conflict' | 'mystery';
  summary: string;                   // ≤ 120 字，给导演的提示
  regionId?: string;
  factionIds: string[];
  npcIds: string[];
  requires: SeedCondition;
  effects: {
    danger: 'low' | 'medium' | 'high';
    threadId?: string;               // 触发后埋下的伏笔
    hint: string;                    // 导演用的一句话预期
  };
  weight: number;                    // 0–100，越大越容易被选中
  once: boolean;                     // 是否只触发一次
};

type SeedCondition = {
  chapterMin?: number;
  chapterMax?: number;
  realmMin?: string;                 // Tier.name
  flags?: Record<string, string | number | boolean>;
  knowledge?: string[];              // 必须已知
  placeId?: string;
};

type EndingRule = {
  id: string;                        // ending_death / ending_fall / ending_ascension / ending_legacy
  type: 'death' | 'ascension' | 'fall' | 'legacy';
  condition: string;                 // 机器可读表达式，见 §13.3
  title: string;                     // 如「身死道消」
  epitaphTemplate?: string;          // 可用 {name} {age} {realm} 占位
};
```

约束：

- `npcPool[*].private` **永不进入叙事 prompt**，只进导演与压缩。
- `eventSeeds` 由引擎按 `requires` 判定，AI 无权自行触发。
- 世界冻结后以上结构不可改；改内容 = 新版本。

## 3. Identity（身份）

```ts
type Identity = {
  id: string;
  name: string;                              // ≤ 12 字
  rarity: 'common' | 'rare' | 'unique';
  difficulty: 1 | 2 | 3;
  situation: string;                         // 处境，≤ 60 字：目标 + 枷锁 + 关系
  goal: string;                              // 长期目标，≤ 40 字
  shackles: string[];                        // ≥ 1，限制与代价
  resources: Record<string, number>;         // 键与 RunState.character.resources 对齐
  relations: { npcId: string; affinity: number; note: string }[];
  start: {
    regionId: string;                        // 必须存在于 bible.regions
    placeId: string;                         // 必须属于该 region
    gameTime: string;                        // "317-03-07"
    age: number;                             // 14–70
  };
};
```

抽取规则：一次抽 3 张，`rarity` 权重 `common: 70 / rare: 25 / unique: 5`；已抽到的身份在同一 `drawToken` 内不重复。

## 4. RunState（运行时状态）

```ts
type RunState = {
  schemaVersion: 1;
  meta: {
    chapter: number;                 // ≥ 1，只由引擎滚动
    turnNo: number;                  // ≥ 0，每回合 +1
    gameTime: string;                // 严格递增
    age: number;                     // 0..lifespan
    lifespan: number;                // 0..9999，只减不增（突破流程除外）
  };
  character: {
    name: string;                    // ≤ 12 字
    identityId: string;
    realm: {
      stage: number;                 // 对应 Tier.stage，只升不降
      stageName: string;             // 冗余存 Tier.name，便于展示与校验
      layer: number;                 // 1..maxLayer
      progress: number;              // 0..100
    };
    stats: {
      vitality: number;              // 气血 0..100，默认 50
      spirit: number;                // 神识 0..100，默认 50
      body: number;                  // 体魄 0..100，默认 50
    };
    resources: {
      spiritStones: number;          // ≥ 0
      pills: Record<string, number>; // 丹药，值为 ≥ 0 的整数
    };
    conditions: Condition[];         // ≤ 10 条
  };
  location: {
    regionId: string;
    placeId: string;
  };
  relations: Record<string, Relation>;   // key = npcId
  inventory: Item[];                     // ≤ 100
  knowledge: string[];                   // ≤ 300 条，每条 ≤ 80 字
  threads: Thread[];                     // 开放 ≤ 50
  flags: Record<string, string | number | boolean>;   // ≤ 200 个键
  reputation: Record<string, number>;    // key = factionId，-100..100
};

type Condition = {
  id: string;                       // 如 cond_wound_left_arm
  label: string;                    // ≤ 20 字
  severity: 1 | 2 | 3 | 4 | 5;      // 5 最重
  turnsLeft?: number;               // 缺省 = 永久直到被治疗
};

type Relation = {
  affinity: number;                 // -100..100
  trust: number;                    // 0..100
  status: '陌生' | '相识' | '熟识' | '信任' | '敌意' | '决裂';
  lastSeenTurn?: number;
};

type Item = {
  id: string;                       // 物品模板 id
  name: string;                     // ≤ 16 字
  qty: number;                      // ≥ 1
  tags?: string[];                  // 如 ['玉','带血']
};

type Thread = {
  id: string;
  desc: string;                     // ≤ 60 字
  dueChapter?: number;
  status: 'open' | 'closed';
  createdAtTurn: number;
};
```

默认值（开局时由 Identity 与内容包计算，不写死）：

| 字段 | 计算方式 |
| --- | --- |
| `stats.*` | 50 + 身份修正（-10..+10），clamp 0..100 |
| `lifespan` | 当前 `Tier.lifespan` |
| `realm` | `stage = 1`，`layer = 1`，`progress = 0` |
| `relations` | 身份卡里的 `relations`，其余 NPC 首次出现时初始化 `affinity 0 / trust 20 / 陌生` |
| `knowledge` | 身份卡自带 1–3 条 |
| `flags` | 空（不预写任何键） |
| `flags.luck` | 不写入，读取时按 `50` 处理（气运，幕后值） |
| `flags.heartDemon` | 不写入，读取时按 `0` 处理；仅突破失败与大失败事件累加 |

读取约定：判定与终局条件中的「气运」取 `flags.luck ?? 50`，「心魔」取 `flags.heartDemon ?? 0`，「根骨」取 `character.stats.body`；三者均不进入面板与叙事数值，见[规则与判定](./规则与判定.md) §10。

## 5. StateDelta 与路径白名单

```ts
type StateDelta = {
  ops: Op[];                        // ≤ 12
  facts: string[];                  // ≤ 6，每条 ≤ 80 字
  openThreads?: Thread[];           // ≤ 3
  closeThreads?: string[];          // ≤ 5
};

type Op = {
  op: 'set' | 'inc' | 'push' | 'remove';
  path: string;
  value?: unknown;
  by?: number;
  reason?: string;                  // 数值 op 必填，≤ 40 字
};
```

### 5.1 可写路径全表

| 路径模式 | 类型 | 允许的 op | 范围 / 约束 |
| --- | --- | --- | --- |
| `meta.gameTime` | string | set | 晚于当前值，格式 `YYYY-MM-DD` |
| `meta.age` | int | set / inc | 0..lifespan |
| `character.realm.stage` | int | set | 只能升，且必须命中 `Tier.stage` |
| `character.realm.stageName` | string | set | 与 stage 同步改，必须命中 `Tier.name` |
| `character.realm.layer` | int | set / inc | 1..当前 Tier.maxLayer，只能升 |
| `character.realm.progress` | int | set / inc | 0..100 |
| `character.stats.vitality` | int | set / inc | 0..100 |
| `character.stats.spirit` | int | set / inc | 0..100 |
| `character.stats.body` | int | set / inc | 0..100 |
| `character.resources.spiritStones` | int | set / inc | ≥ 0 |
| `character.resources.pills.<pillId>` | int | set / inc | ≥ 0 |
| `character.conditions` | Condition | push / remove | 按 `id` 去重，≤ 10 |
| `location.regionId` | string | set | 必须命中 `bible.regions.id` |
| `location.placeId` | string | set | 必须属于当前 region |
| `relations.<npcId>.affinity` | int | set / inc | -100..100 |
| `relations.<npcId>.trust` | int | set / inc | 0..100 |
| `relations.<npcId>.status` | string | set | 枚举见 §4 |
| `inventory` | Item | push / remove | 按 `id` 合并 qty，≤ 100 种 |
| `knowledge` | string | push / remove | 去重，≤ 300 条 |
| `threads` | Thread | push / remove | 按 `id` 去重，开放 ≤ 50 |
| `flags.<key>` | string / number / boolean | set / inc | key 匹配 `^[a-z][a-zA-Z0-9_]{0,31}$`，≤ 200 个 |
| `reputation.<factionId>` | int | set / inc | -100..100，factionId 必须存在 |

### 5.2 禁止写入（硬拒）

| 路径 / 结构 | 原因 |
| --- | --- |
| `schemaVersion`、`meta.chapter`、`meta.turnNo` | 引擎独占 |
| `meta.lifespan` 上调 | 只能由突破流程修改；下调（寿元流逝）允许 |
| `character.identityId`、`character.name` | 开局即定 |
| `character.realm.stage` / `layer` 下调 | 防 AI 随意削境界 |
| `ending_id`、`run.status` | 只能由 `ending.dart` 写 |
| 世界圣经任何字段 | 定义层只读 |
| 未列出的任何路径 | 默认拒绝，不做猜测 |

### 5.3 校验顺序

1. 路径模式匹配（白名单）
2. 类型匹配（int / string / bool / 枚举）
3. 范围 clamp（越界 clamp 而非丢弃；字符串超长截断并记录）
4. 引用完整性（npcId / factionId / regionId / placeId / pillId 必须存在）
5. 单调性（时间递增、境界只升、寿元不升）
6. 死亡封锁（`ending_id != null` 时拒绝一切行动类 op）

**逐条容错**：非法 op 丢弃并写入 `run_events(type='rejected')`，其余继续。

## 6. 回合输入与输出

```ts
sealed class TurnInput {}
class ChoiceInput   extends TurnInput { final String choiceId; }
class FreeTextInput extends TurnInput { final String text; }   // ≤ 200 字

class TurnContext {                    // 调用参数
  final String runId;
  final int expectedTurn;
}

sealed class TurnEvent {}
class TurnStart        extends TurnEvent { final int turn; }
class Classification   extends TurnEvent { final IntentKind kind; final String intent; }
class NarrationDelta   extends TurnEvent { final String text; }
class NarrationEnd     extends TurnEvent {}
class ChoicesAvailable extends TurnEvent { final List<Choice> options; }
class StatePatch       extends TurnEvent { final StateDelta delta; }
class TurnEnd          extends TurnEvent { final int turn; final String snapshotId; final EndingRef? ending; }
class TurnError        extends TurnEvent { final EngineCode code; final String message; final bool canRetry; }

enum IntentKind { action, query, meta, rejected }
type EndingRef = { id: string; type: 'death' | 'ascension' | 'fall' | 'legacy'; title: string };
```

Resolver 输出（纯代码）：

```ts
type ResolveResult = {
  feasible: boolean;
  blockedReason?: string;            // 不可行时给导演的世界内理由
  cost: { timeDays: number; spirit: number; items: { id: string; qty: number }[] };
  check?: {
    stat: 'body' | 'spirit' | 'luck';
    dc: number;                      // 10..95
    successRate: number;             // 5..95
    roll: number;                    // 1..100
    margin: number;                  // successRate - roll，-99..94
    grade: Grade;
  };
};

enum Grade { critical_success, success, narrow, fail, critical_fail }
```

分级映射（与[规则与判定](./规则与判定.md) §4 一致）：

| 条件 | Grade | 中文 |
| --- | --- | --- |
| `roll <= 5` | `critical_success` | 大成功 |
| `margin >= 20` | `success` | 成功 |
| `0 <= margin < 20` | `narrow` | 勉强成功 |
| `-15 <= margin < 0` | `fail` | 失败 |
| `roll >= 96` 或 `margin < -15` | `critical_fail` | 大失败 |

判定顺序：先判 `critical_success` 与 `critical_fail` 的极端值，再按 margin 分级。

## 7. ScenePlan 与 Choice

```ts
type ScenePlan = {
  beat: 'daily' | 'event' | 'turning_point' | 'chapter_end';
  summary: string;                   // ≤ 120 字，给叙事者的指令
  npcActions: { npcId: string; action: string; hidden: boolean }[];   // ≤ 4
  reveals: string[];                 // ≤ 3，必须落到 knowledge
  mood: string;                      // 一个基调词
  nextChoices: {                     // 3–4 条
    intent: string;
    risk: 'low' | 'medium' | 'high';
    requires?: { knowledge?: string[]; items?: string[]; realm?: string };
    hidden?: boolean;
  }[];
  advanceTimeDays?: number;          // 0.5..30
  chapterEnd?: { reason: string };
};

type Choice = {                      // 引擎补全 id 与 label 后下发
  id: string;                        // t<turn>c<n>
  label: string;                     // 8–30 字
  intent: string;
  risk: 'low' | 'medium' | 'high';
  requires?: { knowledge?: string[]; items?: string[]; realm?: string };
  hidden?: boolean;
  check?: { stat: 'body' | 'spirit' | 'luck'; dc: number };
};
```

约束：

- `nextChoices` 必须互斥，不允许两条选项指向同一结果。
- `hidden: true` 的选项在 `requires` 不满足时整条不出现（不是置灰）。
- `check` 由 Extractor 给出则尊重；未给出时由 Resolver 按动作类型推断。

## 8. 世界工坊与导入

```ts
type WorldDraft = {
  id: string;
  source: 'manual' | 'dialogue' | 'import';
  status: 'draft' | 'generating' | 'review' | 'trial' | 'frozen';
  interview?: {
    step: FieldKey;
    answers: Partial<Record<FieldKey, unknown>>;
    completeness: number;            // 0..100
    filledByAI: FieldKey[];
  };
  importJobId?: string;
  bibleDraft?: WorldBible;
  quality: {
    score: number;                   // 0..100，< 70 禁止冻结
    issues: { level: 'error' | 'warn'; field: string; message: string }[];
  };
  exportable: boolean;               // source === 'import' 时恒为 false
  createdAt: number;
  updatedAt: number;
};

type FieldKey =
  | 'era' | 'geography' | 'factions' | 'power'
  | 'taboos' | 'tone' | 'npcPool' | 'seeds';

type ImportJob = {
  id: string;
  sourcePath: string;                // 沙盒私有路径，不导出
  contentHash: string;               // sha256(原文)
  stage: 'parse' | 'extract' | 'merge' | 'review' | 'done' | 'failed';
  progress: number;                  // 0..1
  entityCount?: number;
  error?: string;                    // 面向用户的短句
  createdAt: number;
  updatedAt: number;
};
```

`EndingRule.condition` 使用受限表达式，只允许以下原子与 `&&` / `||` / `>=` / `>` / `<=` / `<` / `==`：

| `stage >= N && layer >= M && progress >= P` | 达到境界条件 |
| `flag("key") == value` | 标记满足 |

引擎只解析以上形式，不执行任意代码。

## 14. 兼容与迁移

| 变更类型 | 处理 |
| --- | --- |
| 新增可选字段 | 不升 `schemaVersion`，读旧数据时补默认值 |
| 新增必填字段 | 升 `schemaVersion`，写迁移函数并在启动时批量补齐 |
| 改字段名 / 类型 | 升 `schemaVersion`，提供 `from → to` 映射；无法映射的字段丢弃并记日志 |
| 删除字段 | 升 `schemaVersion`，迁移时保留原 JSON 于 `legacy` 键一个版本周期 |
| 世界包格式 | `manifest.formatVersion` 独立；导入时只兼容当前与前一版 |

迁移必须满足：幂等、可重跑、失败不破坏原数据（先写临时表再原子替换）。

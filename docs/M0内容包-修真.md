# M0 内容包：苍梧

> 版本：v0.2（单机离线）
> 最后更新：2026-10-23
> 上游：[产品方案](./产品方案.md) ｜ 下游：[UI 与交互](./UI与交互.md)

M0 只做一个世界，但要能玩一卷、能结束、能重开。本文是可直接填入 `world_versions` 的内容资产。

---

## 1. 一句话与基调

**苍梧**：灵脉正在枯竭的末法前夜，修士们还在为最后的资源互相撕咬。

基调：冷峻、克制、少抒情。用动作与物象传递情绪，不解释设定，不替玩家感慨。人命如草芥，但不刻意猎奇。

叙事人称：第二人称「你」。

## 2. 世界概要

### 时代

灵潮退去三百年。老一辈修士靠残留灵脉维持境界，新一代连炼气都艰难。朝廷设缇骑压制修士，宗门靠垄断灵脉收徒，散修在夹缝里抢剩下的渣。

### 地理

| 区域 | 定位 | 用途 |
| --- | --- | --- |
| 云岫城 | 世俗枢纽，市井与黑市 | 前期主要舞台，情报与交易 |
| 栖霞山 | 青莲宗山门 | 外门、内门、宗门政治 |
| 黑水泽 | 散修与魔道聚集地 | 中期危险区，秘境入口 |
| 归墟古战场 | 禁地，灵气紊乱 | 卷末伏笔，深层真相 |

### 势力

| 势力 | 立场 | 核心诉求 |
| --- | --- | --- |
| 青莲宗 | 正道 | 守住最后一条灵脉，压制内部分裂 |
| 玄阴教 | 魔道 | 夺取灵脉，寻找「归墟之钥」 |
| 三合堂 | 市井帮会 | 谁给钱替谁办事，掌握情报网 |
| 缇骑 | 朝廷 | 清查灵脉枯竭真相，收编或清除修士 |

### 力量体系

灵根 → 引气入体 → 炼气（九层）→ 筑基（三期）→ 金丹（三品）→ 元婴（三重）。

硬规则（写入 `powerSystem.rules`）：

1. 灵力不可凭空恢复，必须吐纳或服丹。
2. 越阶斗法，境界差每层压制 12 点成功率。
3. 心魔无法靠丹药清除，只能靠事件化解。
4. 突破必须闭关，中途被打断即失败并受伤。

禁忌（写入 `taboos`）：

1. 归墟古战场不得深入第三重。
2. 不得以活人祭炼。
3. 宗门内不得杀同门（违者全宗追杀）。

## 3. 文风样例

> 你把手缩进袖子里。风从山门那边过来，带着一股铁锈味。
>
> 守门的弟子看了你一眼，又低下头去。他没有问你为什么迟到两个时辰，也没有问你袖口那道还没干的血。他只是把名册翻过一页，念了下一个名字。
>
> 你听见自己的名字被念出来时，喉咙里有一点点发甜。

字数 120，第二人称，无内心独白代替玩家，无设定解释。

## 7. 第一卷骨架

| 段落 | 回合 | 内容 | 关键选择 |
| --- | --- | --- | --- |
| 序章 | 0 | 身份落地，第一段处境描写 | 是否亮出玉牌/玉简（暴露 vs 隐藏） |
| 第一幕 立足 | 1–10 | 活下去，找到第一个信息源，卷入一件小事 | 站队：宗门 / 市井 / 独行 |
| 第二幕 代价 | 11–22 | 第一次真正的损失：师父、同伴或身份 | 保人还是保己 |
| 第三幕 卷末 | 23–31 | 秘境开启或宗门清洗，两条线只走一条 | 入秘境 / 留城中 |
| 卷末 | 32 | 突破筑基判定，成功入第二卷，失败转入残局 | 是否冒死突破 |

卷末无论成败都触发压缩与结算检查，玩家可以在此存档离开。

## 8. 终局条件

| ID | 类型 | 条件 | 结算标题 |
| --- | --- | --- | --- |
| ending_death | death | 气血归零且濒死判定失败，或寿元耗尽 | 身死道消 |
| ending_ascension | ascension | 元婴圆满 + 归墟真相 + 特定选择 | 破界而去 |
| ending_fall | fall | 心魔 ≥ 5 或突破大失败 | 走火入魔 |
| ending_legacy | legacy | 放弃修行，把真相留给后人 | 人间留名 |

M0 至少要实现 `ending_death` 与 `ending_fall`，其余可作为第二卷目标。

## 9. 与引擎的字段对应

| 内容 | 落库位置 |
| --- | --- |
| 时代、地理、势力、力量体系、禁忌 | `world_versions.bible` |
| 身份池 | `world_versions.identities` |
| 事件种子 | `world_versions.seeds` |
| NPC 公开面 | 叙事 prompt 的检索段 |
| NPC 私密面 | 导演 prompt 的检索段，标记 `hidden: true` |
| 第一卷骨架 | 不作为数据，作为导演的节奏参考写入系统段 |

## 10. 内容边界

1. 暴力写后果，不写细节；不描写折磨过程。
2. 不映射现实宗教、民族、政治事件。
3. 未成年角色不参与任何亲密关系。
4. 不生成可操作的现实危险行为指导。
5. 所有分享的世界包与 AI 生成内容过统一本地审核管线。

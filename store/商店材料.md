## 2. 商店文案

### 2.1 短描述（Google Play，80 字符内）

> 装进口袋的 AI 单人跑团：一个世界，一段有始有终的人生。

### 2.2 副标题（App Store，30 字符内）

> 装进口袋的 AI 单人跑团

### 2.3 完整描述

远行是一个装在你手机里的单人跑团。

你会进入一个完整的世界，被分配一个身份，然后过完一段有始有终的人生。AI 担任幕后的 GM，推进世界与 NPC；关键节点会停下来，让你决定往哪走。你可以选择，也可以自己写下想做的事。

**它和聊天机器人不一样**
- 数值、生死、时间与判定由本地规则裁决，AI 只负责叙事与选项，不能随意改写你的状态。
- 每一次选择都有代价。身份不是职业，而是你此刻的处境与枷锁。
- 死亡是结局，不是失败。终局会留下人生档案，你也可以从关键节点分叉出另一条世界线。

**你可以**
- 在书架里选择世界，抽取三个身份，选一个开始。
- 在关键节点做选择，或自由输入行动。
- 随时向不推进剧情的随行助手提问，它不会剧透。
- 把世界打包成 `.world` 分享给朋友，把存档打包成 `.run` 换设备续玩。
- 用自己创作或获授权的 TXT 小说生成一个可游玩的世界。

**关于模型与费用**
远行没有账号、没有云端存档，也没有自建模型服务。剧情生成需要你自备兼容 OpenAI Chat / OpenAI Responses / Anthropic 协议的模型服务 Key；Key 只保存在系统安全存储中，请求由设备直连你选择的服务商，模型费用由你自行承担。没有 Key 时仍可离线阅读已有存档与世界观。

**内容提示**
本作是虚构作品，包含死亡、暴力后果与人性困境的描写，不构成现实建议。AI 生成内容可能有误。未成年人请在监护人指导下使用。

**隐私**
世界、存档、草稿与用量保存在本机；除模型请求外不联网。没有账号、没有社区、没有公开榜单。完整数据处理说明见隐私政策：【待填写：政策 URL】。

### 2.4 关键词（App Store，100 字符内）

> 跑团,文字冒险,单机,离线,修仙,仙侠,角色扮演,AI,世界,人生模拟,互动小说

## 4. 内容分级

按实际问卷逐项确认，建议口径：

| 问卷项 | 建议答案 | 说明 |
| --- | --- | --- |
| 暴力 | 轻度 / 偶发 | 文字描写死亡与暴力后果，无血腥画面 |
| 性内容 | 无 | — |
| 粗俗语言 | 无 | 本地词表拦截高危输入 |
| 毒品 / 酒精 | 无 | 世界观可提及，但不美化 |
| 赌博 | 无 | — |
| 恐怖 | 轻度 | 世界观含鬼市、尸傀等文字设定 |
| 用户生成内容 | 有（本机） | 自由输入与小说导入仅存本机，无公开分发 |
| AI 生成内容 | 有 | 叙事、选项、人生卡片均由 AI 生成，界面与导出物有标识 |

- Google Play 建议分级：12+（以 IARC 问卷结果为准）。
- App Store 建议分级：13+ 或 16+（按暴力描写问卷复核；Apple 现行档位为 4+/9+/13+/16+/18+）。

## 5. 数据安全 / App 隐私

| 项 | 口径 |
| --- | --- |
| 开发者是否收集数据 | 否。无账号、无自有后端、无统计上报 |
| 数据是否离开设备 | 是，仅在用户主动推进回合/导入/测试连接时发往用户自选模型服务商 |
| 是否与第三方共享 | 用户内容会发送给用户配置的服务商；该服务商由用户选择，开发者不代持 Key、不中转 |
| 是否用于追踪 | 否 |
| 数据删除 | 设置页「清空全部数据」冷启动清理；单局/世界/诊断可单独删除 |
| 隐私政策 URL | 【待填写】 |
| 支持 URL | 【待填写】 |

- App Store 隐私清单已在工程内提供 `apps/mobile/ios/Runner/PrivacyInfo.xcprivacy`（无追踪、无开发者收集、声明 UserDefaults / 文件时间戳 / 磁盘空间 / 启动时间四类 Required Reason API）。
- 若审核将「用户内容发送至自选模型服务商」认定为共享：App Store「App 隐私」可按 User Content（其他用户内容）→ App Functionality 申报，不用于追踪、不与身份关联（本应用无账号）；Google Play Data Safety 在「用户内容是否发送至第三方」处如实选择。最终勾选以【待填写：发行主体】的法务结论为准。

- 具体「收集/共享」勾选与法务结论以【待填写：发行主体】确认为准。

# WayfarerPhone · 世界人生模拟器

一个「世界可生成、可分享」的 AI 单人跑团，**装在你手机里的单机 App**。

玩家进入世界、被分配身份、过完一段人生；AI 担任幕后 GM 推进世界与 NPC；关键节点停下让玩家选择方向；随时可向一个不推进剧情的「穿越助手」提问。

> 当前阶段：**方案阶段，尚未开始编码**。文档覆盖 M0 的全部设计与契约，并给出 M1–M3（世界工坊、小说导入、本地分享）与双端上线的机制契约。
>
> v0.3 形态：iOS + Android 双端 Flutter App，**无服务端、无账号、无社区**。数据全部在手机本地 SQLite；模型由用户自带 Key 直连所选服务（OpenAI Chat / OpenAI Responses / Anthropic 三协议）；世界通过 `.world` 分享，存档通过 `.run` 迁移。

## 产品形态（一句话）

| 项 | 结论 |
| --- | --- |
| 运行位置 | 手机本地（iOS / Android），除模型请求外全程离线 |
| 数据 | 本地 SQLite（drift），随 App 沙盒，可导出备份 |
| 模型 | 用户自带 Key，直连所选服务（OpenAI Chat / OpenAI Responses / Anthropic 三协议）；Key 存 Keychain / Keystore |
| 世界分享 | `.world` 文件，经系统分享面板导出、文件选择器导入 |
| 账号 / 社区 | 无。没有登录、没有公开榜单、没有举报后台 |
| 费用 | App 一次性付费；模型 token 费用由用户自己的 Key 承担 |

## 已定决策

| 决策项 | 结论 |
| --- | --- |
| 一局形态 | 单世界、单身份、一段有始有终的人生（非无限流、非沙盒） |
| 裁决方式 | 规则 + AI 混合：代码管数值/生死/时间/判定，AI 管叙事与选项 |
| 运行形态 | 纯单机离线 App，iOS + Android 首发，一套 Dart 业务层 |
| 数据存储 | 设备本地 SQLite（drift），无云端、无账号 |
| 模型接入 | 用户自带 Key，直连三家协议之一（OpenAI Chat / OpenAI Responses / Anthropic）；Key 存系统安全存储 |
| 世界分享 | 本地 `.world` 包，经系统分享面板传递，无公开分发与社区 |
| 存档迁移 | 独立 `.run` 包，与 `.world` 解耦，跨设备续玩 |
| MVP 目标 | 先验证「玩」，只做内置世界 |
| 玩家动词 | 关键节点选项 + 自由输入 |
| 单局长度 | 不设上限，可存档续玩，直到终局 |
| 首发题材 | 修真 / 仙侠，世界名「苍梧」 |
| 商业模式 | 一次性付费，无内购、无订阅 |
| 模型协议 | 三协议适配：OpenAI Chat Completions / OpenAI Responses / Anthropic Messages；内置 DeepSeek 与 OpenAI 预设，另可自定义 |
| 视觉呈现 | 纯文字 + 排版，不做 AI 配图 |
| 关系系统 | 两轴：亲和 + 信任；在此之上只用六档关系标签，不做道侣/师徒/结拜系统 |
| 助手模式 | 仅随行模式，禁止剧透；问世界真相一律不答 |
| 记忆检索 | M0–M3 用实体标签 + FTS5，不引入向量检索，预留接口 |
| 平台范围 | 首发只保证 iPhone + Android 手机；iPad / Mac 不承诺体验 |

## 五条不可妥协的原则

1. 叙事是表现层，状态是唯一真相。
2. AI 只提议，代码裁决。
3. 身份是处境，不是职业。
4. 选择稀缺且有代价。
5. 死亡是结局，不是失败。

这五条写在 [产品方案](./docs/产品方案.md)，并已落到 Prompt 铁律、校验规则与判定系统里。

## 术语表

| 术语 | 含义 |
| --- | --- |
| 世界圣经 `WorldBible` | 世界的完整定义：时代、地理、势力、力量规则、禁忌、NPC、种子，版本化后冻结 |
| 身份 `Identity` | 一局的初始处境，决定资源、关系、目标与枷锁 |
| 局 `Run` | 玩家的一次人生，绑定世界版本与身份 |
| 快照 `Snapshot` | 某一回合的完整 `RunState`，可分支 |
| 编年史 `run_events` | append-only 事件流，可回放、可生成人生档案 |
| 事实清单 `facts` | 已发生且不可推翻的既成事实 |
| 伏笔 `Thread` | 已埋下但未回收的线索，带回收期限 |
| 已知信息 `knowledge` | 主角知道的，不等于世界真相 |
| 场景计划 `ScenePlan` | 导演的输出：本回合发生什么、释放什么信息、下一批选项意图 |
| 判定 `Resolver` | 纯代码执行的可⾏性、消耗、掷骰与结果分级 |
| 世界线 | 从某个快照分叉出的新局，旧局原样保留 |
| 卷 `Chapter` | 一个境界或人生阶段，20–40 回合，卷末压缩 |
| 草稿 `WorldDraft` | 未冻结的世界，可反复修改；冻结后成为版本 |
| 本地世界库 | 设备上所有世界的集合：内置、自建、导入、他人分享 |
| 世界包 `.world` | 分享与导入的 zip 产物，含 manifest、世界定义、`NOTICE.txt` 与校验和 |
| 模型网关 `ModelGateway` | App 内唯一的模型出口，负责 OpenAI 兼容请求、流式解析、重试与记账 |
| 自带 Key | 用户在设置页填入的模型服务凭证，存 Keychain / Keystore，不经任何自家后端 |
| 串行队列 | 同一局同时只处理一个回合的进程内机制，替代云端锁 |
| 卷末压缩 | 每卷结束时把本卷事件压成事实清单、关系变化、伏笔与 300 字卷记 |
